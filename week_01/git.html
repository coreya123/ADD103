Git and GitHub

1. Understanding Git and GitHub

Git is installed via the command line and runs on the local machine. GitHub is a cloud service that allows you to store and share Git projects online.

2. VS Code Source Control Process

Save the file by pressing command S.

Open the source control panel.

Type a commit message that describes what changes were made.

Press the blue commit button.

Press the sync changes button.

Check on GitHub that the changes were pushed to the repository.
